# 개인 AI 변경내역

## 2026-10-19 — 로컬 검토용 구현

1. 원본 저장소·기준 커밋을 확인하고 사용자 지정 Desktop 폴더로 작업 위치를 확정. 이전 임시 사본에서는 요구사항 문서만 작성했으며 구현은 지정 폴더에서 수행.
2. 확보 가능한 대화 선택만 요구사항 R01–R54로 정리. 원문88개 대조와 마지막 분당 제한 UX를 미확정으로 명시.
3. AI 도메인·개인정보 검사·목적 선택·7일 만료·취향 학습 모듈 추가.
4. 서버 전용 AI 테이블과 트랜잭션 RPC migration 추가. 성공 결과 원자 저장, 동시1개, 전역 일일/분당 호출 상한, 변경 버전 검사, 관리자 집계·감사·만료 정리 구현.
5. Gemini SSE 연결, JSON 검증, 취소·시간초과·재시도·완료복원 API 추가.
6. 홈 도우미와 관리자 AI 설정 패널 연결. 추천·대화·보관함·편집·초안 충돌·개인정보 확인 UI 추가.
7. 검토 중 로컬 Origin 비교, 신형 Supabase secret key 헤더, SQL 조건문, 만료 방제목, 보관본 버전 충돌, 이전 대화 개인정보 익명화 경로 보완.
8. 기존125개를 포함한 총150개 테스트와 DB29개·HTTP17개 검사를 통과. 실제 화면 흐름과 390×844 모바일 전체화면 확인.
9. 운영과 분리된 검토 실행기·검증 스크립트·구현 보고서 추가. push/배포/운영 DB 적용 없음.

## 주요 변경 경로

- `src/lib/ai/`: 데이터 타입, 개인정보, 만료/취향/맥락, 추천 목적, 도메인 테스트.
- `src/server/ai/`: 저장소, 액션, Gemini, 생성 수명주기, HTTP 경계와 테스트.
- `src/app/api/ai/`, `api/admin/ai/`, `api/internal/ai-cleanup/`: AI API 및 권한.
- `src/components/ai-assistant.tsx`, `ai-assistant.css`, `ai-admin.tsx`: 화면.
- `learning-crew-app.tsx`, `admin-app.tsx`: 기존 화면에 진입점만 연결.
- `supabase/migrations/20261019065739_personal_ai_assistant.sql`: 아직 운영 적용하지 않은 migration.
- `src/worker.ts`, `wrangler.jsonc`: 기존 알림 cron 보존, AI 정리 cron 추가.
- `.env.example`: Gemini 서버 환경변수 예시. 실제 `.env.local` 수정 없음.
- `scripts/preview-ai.mjs`, `test-ai-database.mjs`, `test-ai-preview.mjs`: 로컬 체험 및 검증.
- `package.json`, `package-lock.json`: 검토/DB 검사 명령 및 테스트용 PGlite 정확한 버전 추가.

원복이 필요하면 AI 진입점과 위 신규 파일을 검토해 선택적으로 되돌린다. 사용자 작업·이미지를 지우는 일괄 초기화 명령은 사용하지 않는다.

## 2026-10-19 — 홈 시작 동선 통합

- 홈의 별도 3분 미션 카드를 제거하고 AI 도우미 대화의 가볍게 시작하기로 통합.
- 할 일 정리·긴 글 요약·아이디어 3개 예시 제공. 기존 /api/missions의 관리자 지정 미션과 기본 일일 미션도 오늘의 시작 아이디어로 유지.
- 예시 클릭은 입력창 채우기와 포커스만 수행. 전송 전 Gemini 호출·한도 차감·대화방 생성 없음.
- 새 대화에서는 예시 펼침, 기존 대화에서는 접힘. 최근 대화 우선 선택 유지.
- 기존 개인 추천3/대화5, 전체 일100/분5 설정 유지. 배포하지 않고 127.0.0.1:3101에서 검토.
- 검증: ESLint 통과, Next.js 빌드(타입 검사 포함) 통과, 기존 자동 테스트 150개 통과. 실제 3101 화면에서 홈 미션 제거, 예시 3개와 일일 아이디어의 입력창 채우기, 클릭 후 잔여 횟수/방 목록 유지, 390×844 전체화면 확인. 이번 UI 검증은 Gemini 요청을 전송하지 않음.
